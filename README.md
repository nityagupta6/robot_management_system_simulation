# robot_management_system_simulation

How to run this project-

1. Open the terminal in your system.
2. ⁠ git clone <link_of_the repository>
2. Navigate the directory in the system.
3. Enter the following commands in the root directory of the project:
4. python3 -m venv <name>
5. source <name>/bin/activate
6. ⁠pip install networkx matplotlib numpy opencv-python
7. ⁠python3 robot_simulation.py
8. A simulation window will open you can enter the required number of robots and press Reset button.
9. Enter Play button to start the simulation. Pause to stop it.
10. You can also use arrow keys to move back and forth the simulation steps. (P.S. It only works when the simulation is paused)
